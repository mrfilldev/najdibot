# najdibot

Telegram-бот @najdibot на Cloudflare Workers (+ Container для скачивания).

## Навыки
| Что | Как вызвать |
|---|---|
| Поиск товаров, 25 площадок РФ по категориям | `найдибля <запрос>`; в личке просто запрос; inline `@najdibot запрос` |
| Глобальный поиск (Google, Amazon, eBay, AliExpress, Temu, Etsy) | `найди <запрос>`; inline `@najdibot найди запрос` |
| Скачивание видео YouTube / Shorts / TikTok / Instagram Reels | просто кинуть ссылку (до 50 МБ, H.264) |
| Музыка (mp3 до 15 минут) | `сыграйбля <название или ссылка>` |
| Диджей: стартовый трек, дальше бот сам подбирает следующие по истории сессии (LLM), до 10 подряд; Telegram сам проигрывает их по очереди | `диджейбля <название или ссылка>`; выключить: `диджейбля стоп` |
| Место на карте со стёбом | `найдибля координаты <фраза>` (и inline) |
| Шутка на матерный запрос | любой запрос с матом |
| Ругань на чужих ботов через LLM | ответить на сообщение чужого бота |
| Случайный лай в группах | сам, ~4% сообщений |
| Голосовое в ответ на «ГАВ ГАВ ГАВ» (3+ «гав» подряд) | написать в чат |
| Участник чата: помнит последние ~300 сообщений (D1), раз в ~50 сообщений сам решает: текст / реакция / мем с Reddit (meme-api.com) / молчать; на `@najdibot` и реплай отвечает всегда | в группах сам; `/forget` стирает свои сообщения из памяти |
| Голосовое в ответ на фразу «а робот может сочинить симфонию?» | написать эту фразу в любом чате |
| Голосовая погода в стиле мема: Open-Meteo + LLM + озвучка (OpenRouter gpt-audio-mini) + ffmpeg (хрипота, тон выше) | «какая щас погода в Москве» (Москва, Питер, Казань, Екатеринбург, Новосибирск, Сочи, Краснодар) |
| Игровой автомат 🎰: фразы пишет LLM по тому, что выпало на барабанах (проигрыш — горевание с матом, джекпот — оскорбление случайного участника чата с тегом); при сбое LLM берутся готовые фразы | «депни в казик» (джекпоты: 1, 22, 43, 64) |
| Юмористическая сводка чата: сама в 18:00 и 00:00 (МСК) и по `/сводка` | группа, где за 12 ч было 8+ сообщений |
| Отсылки к мемам в репликах LLM (вбросы, казино, ругань, сводка), примерно в каждой третьей | само, `MEME_HINT` в `worker/chat.js` |
| Модерация (только админы, ответом на сообщение): /mute, /unmute, /ban, /unban, /kick, /del, /warn, /unwarn, /warns | в группе; боту нужны права админа «удалять сообщения» и «блокировать пользователей» |
| «Доебись»: бот цепляет участника с тегом и ведёт с ним диалог (до 4 реплик, 10 минут, шанс продолжить падает с каждым ходом, «отстань» от цели сворачивает сразу) | `Санни доебись до Кирилла` или `до @ника` (имена бота: найдибля, найдибот, @najdibot, Санни, Sunny, Саныч, Сан-Саныч, Саня, Сань, Санёк), ответом на сообщение или `до кого-нибудь`; `Санни отстань` — стоп |
| Инструменты в прямых ответах: поиск в интернете (плагин web у OpenRouter), чтение страниц по ссылке (Jina Reader), разбор фото | обращение к боту по имени, в том числе ответом на сообщение со ссылкой или фото |
| Правила доёба | `/rules_of_doeb` (или `/rules-of-doeb`) |
| Живой диалог: 10 минут после ответа бот по смыслу (LLM) решает, обращена ли реплика человека без имени к нему | автоматически |
| Настроение Санни: само меняется (раз в ~25 мин модель решает по переписке и времени суток) и от событий (казино, ревность к чужим ботам, когда его послали); окрашивает все его реплики | автоматически; `/mood` показывает текущее |
| Отношение Санни к каждому человеку (-5…+5 с причиной): меняется от событий (послали, похвалили) и оценки модели, со временем затухает; влияет на тон (плюс: без мата и добрее с ростом оценки; минус: мат и жёстче с ростом минуса), выбор мишени в казино и ответы; можно спросить «Санни, как ты относишься к Дане?» | `/relations` показывает: любимчики, враги, нейтрально |
| Извинился перед ботом («извини», «прости», «сорян», «погорячился»): отношение поднимается минимум до +2 | автоматически, если обратиться к боту по имени или ответом |
| Санни о себе: как часто, что умеет, как дружить и как поругаться | `/about` или вопрос «Санни, расскажи о себе / что умеешь / как с тобой дружить» |
| Потише: 3 часа без самовольных вбросов, отвечает только на прямое обращение | «Санни, потише» / «полегче» / «сбавь темп» / `/quiet`; вернуть: «Санни, громче» / `/loud` |
| Таймаут: Санни уходит спать на N часов (по умолчанию 6) и молчит полностью (на обращение только реакция 😴, сводку не шлёт) | «Санни, поспи» / «возьми таймаут на 6 часов» / `/sleep 6`; будить: «Санни, проснись» / `/wake` |
| Серьёзный режим: на «объясни/поищи/найди/проанализируй/сравни/посчитай/переведи» (по имени или ответом) отвечает по делу, с поиском, без мата | автоматически |
| Справка | `/help`, `/start` |

## Устройство
- `worker/index.js` — Worker: webhook Telegram, триггеры, inline, LLM (OpenRouter).
- `container/` — контейнер с `yt-dlp` и `ffmpeg` для видео и музыки.
- `legacy-python/` — первая версия на aiogram (polling), не используется.
- Секреты в Worker: `BOT_TOKEN`, `WEBHOOK_SECRET`, `OPENROUTER_API_KEY`. Модель — `LLM_MODEL` в `wrangler.toml`.
- Деплой: `DOCKER_CONTEXT=desktop-linux npx wrangler deploy`; webhook: `./set-webhook.sh <url>`.

## Служебное
- `POST /debug {"query": "..."}` и `POST /restart` с заголовком `X-Telegram-Bot-Api-Secret-Token` (= `WEBHOOK_SECRET`):
  пробная загрузка в контейнере с реальной ошибкой и принудительный перезапуск экземпляра.
  После `wrangler deploy` живой контейнер продолжает работать на старом коде, пока не уснёт (10 мин), поэтому нужен `/restart`.
- Контейнеру нужен `--js-runtimes node` для `yt-dlp`, иначе YouTube отвечает 403.
- `yt-dlp` качает сначала анонимно, при ошибке повторяет с cookies (`runYt`): с cookies с IP Cloudflare YouTube быстро начинает отвечать 403, а без них работает стабильно.
